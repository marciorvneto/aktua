# tiny-ctrl

**tiny-ctrl** is a small, experimental programming language for control systems and numerical computing, written in C.

It's a work in progress.

You can use it interactively through a REPL or execute scripts from the command line.

## Example

Level control of a leaky tank with a PI controller ([`examples/leaky_tank.tc`](examples/leaky_tank.tc)):

```rust
// Level control of a leaky tank with a PI controller.
// See tank_level_control.tc for where these numbers come from.
// By: Marcio R. V. Neto, 2026

let s = poly([0, 1])

let H = 0.2 / (100 * s + 1)    // Tank: level [m] per inflow [L/s], time constant 100 s
let C = 20 + 0.2 / s           // PI controller
let W = C * H / (1 + C * H)    // Closed loop: level setpoint -> level

print(W)
print(poles(W))

let t = linspace(0, 150, 151)
plot(t, step(W, t))
```

## Quick start

Build the project and start the REPL:

```console
$ make
$ ./build/tctl
```

Try a few commands:

```text
tiny-ctrl> let x = 3
tiny-ctrl> x

3

tiny-ctrl> let p = poly([1,2,3])
tiny-ctrl> p

3 x^2 + 2 x + 1

tiny-ctrl> 1/p

       1
---------------
3 x^2 + 2 x + 1
```

You can also execute scripts directly:

```console
$ ./build/tctl examples/leaky_tank.tc
```
